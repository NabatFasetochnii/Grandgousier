# Grandgousier 0.5.33.2

Добавлен отдельный режим candidate-excluded ensemble до сходимости:

```text
--candidate-ensemble-until-converged
--candidate-ensemble-convergence-max-iterations N
```

Fixed iteration mode сохранён без изменения. Manifest получил convergence diagnostics, final candidate set и stop reason.

Контрольный запуск BK Lyn 2026-03-28 сошёлся на ensemble iteration 6 при cap 10. После него terminal history entry для iteration 7 имела `executed=false`, что выявило ошибку сводных actual exclusion полей и стало причиной патча 0.5.33.3.
