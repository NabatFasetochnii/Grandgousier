# ADR 0001: Разделить живой контекст, архитектуру и историю релизов

Статус: принято.

Дата: 2026-08-01.

## Проблема

Один большой context-файл смешивал актуальное состояние, команды, историю патчей и будущие планы. При переносе в новый чат было трудно отделить подтверждённые факты от устаревших.

## Решение

- `CONTEXT.md` остаётся коротким индексом и не генерируется автоматически.
- Актуальная информация хранится в `docs/context/`.
- Машиночитаемое резюме хранится в `context/project_state.yaml`.
- Причины архитектурных решений хранятся в `docs/decisions/`.
- История версий хранится в `docs/releases/`.
- `scripts/build_context_bundle.py` создаёт переносную копию для чата, но не становится источником истины.

## Последствия

Контекст требует обновления нескольких небольших файлов, зато новый чат получает короткий и однозначный маршрут чтения. История Git/release notes больше не копируется целиком в текущий статус.
