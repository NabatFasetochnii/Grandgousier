# Grandgousier 0.5.33.3

Дата: 2026-08-01.

## Исправление

`quality_policy.candidate_ensemble_actual_excluded_reference_object_ids` и соответствующий count теперь берутся из последней выполненной candidate-excluded ensemble iteration, а не безусловно из последней history-записи.

Добавлено поле:

```text
candidate_ensemble_actual_exclusions_iteration
```

Оно показывает номер ensemble iteration, которой соответствуют top-level actual exclusions.

## Regression test

Добавлен сценарий:

- iteration 6 выполнена и имеет actual exclusions;
- iteration 7 является terminal convergence check с `executed=false`;
- top-level actual exclusions остаются данными iteration 6.
